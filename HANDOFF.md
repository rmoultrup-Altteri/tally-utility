## Failed Approaches (Don't Repeat These)
- **`timeout 900 python ...` in the shell** -> macOS has no `timeout`: `(eval):10: command not found: timeout`, exit 127, the run never started -> run the command directly in the background.
- **Bulk `s.replace('"fraction": 0.5', ...)` over the runner** also rewrote the test line that builds the non-canonical-number case, so it silently matched nothing and reported "was not refused" -> the case now asserts `'"fraction":0.50' in text` before using it.
- **Floats in `terms-15.py` documents** -> `lawc.LawError: cannot serialise float` -> use `Decimal("0.5")`.
- **Python heredoc whose SQL contains `'''statute'''`** inside a `'''` string -> `SyntaxError` -> write long SQL chunks with the Write tool to the scratchpad and append them from Python.
- **`INSERT ... SELECT 'literal'` for numeric columns** (first `dep_sql`) -> unknown literals become text in a SELECT list and do not coerce to numeric -> use `INSERT ... VALUES`.
- **A wait loop with `grep -q ... || exit 1` as a Monitor** raised a false "failed" notice; the run itself was fine -> poll the output file and read it.
- **Overlapping tariff dates in group N** would have made tests fail on the exclusion constraint instead of the guard they name -> one residential tariff at a time (dates fixed).
